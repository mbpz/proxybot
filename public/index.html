Get Started

  1. brew install mbpz/proxybot/proxybot-tui
  2. Connect phone to same WiFi as Mac
  3. Set phone's gateway and DNS to Mac's IP
  4. Export CA cert from Certs tab → AirDrop to phone
  5. Trust CA in iOS Settings → General → About → Certificate Trust
  6. Run proxybot-tui and press r to start

Find your Mac IP: ipconfig getifaddr en0
