# Historical product and design records

Files in this directory preserve research and earlier product proposals. They
are not current release claims and may describe removed interfaces, unsupported
experiments, stale competitor data, or implementations that never reached the
desktop composition root.

Use these sources in this order when they disagree:

1. current code and executable tests
2. [`CONTEXT.md`](https://github.com/mbpz/proxybot/blob/main/CONTEXT.md) for domain language and relationships
3. the active [product roadmap](../roadmap.md)
4. current user and architecture documentation
5. historical records in this directory

Before implementing an old proposal, open a focused issue and revalidate its
user need, product tier, security boundary, and real-Adapter acceptance test.
