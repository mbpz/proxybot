# Release candidate 0.2.0 (2026-10-28)

## Artifact

```text
target:   aarch64-apple-darwin
archive:  minimal/dist/proxybot-min-aarch64-apple-darwin.tar.gz
sha256:   444f96c7607ecf7da82c7e89f5fceeb4cde670bf505b02bbe72a52e659f1d319
```

`0.2.0` is the Gateway Beta / lifecycle release. `minimal/CHANGELOG.md` records
the feature set; the archive doesn't contain sing-box.

## Verified locally

- `cargo test` (6 tests) passed; release build/package succeeded.
- `install.sh` with `PROXYBOT_LOCAL_ARCHIVE` verified SHA-256 and installed
  0.2.0 into a temporary prefix.
- License and `THIRD_PARTY.md` are installed under
  `<prefix>/share/proxybot/`; `uninstall.sh` removes them and the binary.
- Fresh data-directory start created the DB and served `/api/requests` on an
  alternate port; this also caught/fixed a fresh-schema migration bug where
  provenance indexes were created before their columns.
- Archive contains no sing-box binary/source.

## Not verified

- Upgrade from an installed 0.1.11 binary to 0.2.0 (reinstall mechanics only).
- A truly clean external Mac with no repository/caches.
- External-user acceptance of CA install, gateway phone flow and certificate

- GPL/legal review of any future bundled sing-box distribution.
