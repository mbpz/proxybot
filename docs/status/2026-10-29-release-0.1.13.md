# Release candidate 0.1.13 (2026-10-29)

0.1.13 is the next small release after the latest GitHub release, v0.1.11. It
contains the Gateway Beta and maintenance work accumulated locally.

## Contents

- Gateway Beta: TUN + sing-box + Hudsucker, HTTP/80 adapter, QUIC policy,
  supervisor, launchd service, device identity/source routing.
- `proxybot uninstall` with data/CA prompts, verified CA fingerprint matching,
  `--purge --yes`; `proxybot update` with SHA-256 verification.
- Full `proxybot list`; focused top-level help.
- Archives include `proxybot`, `LICENSE`, `THIRD_PARTY.md`, `uninstall.sh`; no
  sing-box.
