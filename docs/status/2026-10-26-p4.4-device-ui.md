# P4.4 device/source UI and identity filters

## Data contract (frozen)

- `client_ip` is a **current source address**, not a permanent device identity.
- `device_id` stays NULL until a real device registry exists; the UI shows
  "unregistered" rather than inventing an ID.
- Source groups are built from request `client_ip`; `source_ip_cidr` is not a
  display identity.
- Unknown identity means all of:
  ```sql
  source_type = 'gateway'
  AND client_ip IS NULL
  AND identity_source = 'unknown'
  AND confidence = 'unknown'
  ```
  Explicit-proxy rows with a real peer IP are not counted as unknown even though
  their `identity_source` is `unknown`.
- `confidence` is displayed literally and never upgraded by the UI:
  - `inferred` → "inferred"
  - `confirmed` → "confirmed"
  - `unknown` → "identity unknown"
- Existing rows are not rewritten; the additive migration just supplies
  defaults.
- Pagination is `limit` + `offset`, ordered by `ts DESC, id DESC`.

## Backend

- `GET /api/requests` accepts `client_ip`, `source_type`, `unknown=true`,
  `limit`, `offset` in addition to existing filters.
- `GET /api/devices` returns source groups:
  - `sources`: `client_ip`, `source_type`, `identity_source`, `confidence`,
    `device_id: null`, count, last_ts;
  - `unknown_count` for the gateway unknown semantics above.
- Store tests cover client-IP filtering, unknown filtering, source grouping and
  exclusion of local-proxy rows from `unknown_count`.

## UI

- Source filter dropdown: All sources, observed source IPs with counts, and
  "Unknown identity". Source chips were removed to keep one interaction path.
- Source column per row: current IP or `unknown`, plus identity label
  (`local proxy`, `inferred`, `identity unknown`).
- Detail view: source, peer IP, device (unregistered), identity_source,
  confidence, connection_id.
- "View source requests" from a detail with a client IP; disabled for unknown.
- Reset filters and "Load older" pagination.
- Empty state for no matches.

- `GET /api/devices`, `client_ip=...`, and `unknown=true` exercised against a
