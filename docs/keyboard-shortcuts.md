# Keyboard Shortcuts

ProxyBot TUI supports full keyboard navigation. Below are all available shortcuts.

## Proxy Controls

| Shortcut | Action |
|----------|--------|
| `r` | Start/Stop proxy |
| `p` | Toggle pf (packet filter) |
| `n` | Toggle DNS server |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Tab` | Next tab |
| `Shift+Tab` | Previous tab |
| `j` | Move down (in lists) |
| `k` | Move up (in lists) |
| `Enter` | Select / confirm |

## Traffic Tab

| Shortcut | Action |
|----------|--------|
| `m` | Filter by method |
| `f` | Filter by host |
| `o` | Filter by status code |
| `a` | Filter by app tag |
| `/` | Open search |
| `x` | Clear all filters |
| `Esc` | Cancel input |
| `1` / `2` / `3` | Switch detail sub-tab (Headers / Body / WS Frames) |

## Rules Tab

| Shortcut | Action |
|----------|--------|
| `a` | Add rule |
| `e` | Edit rule |
| `d` | Delete rule |
| `j` / `k` | Navigate list |

## Devices Tab

| Shortcut | Action |
|----------|--------|
| `a` | Toggle ADB (USB debugging) |
| `e` | Edit device rule override |
| `j` / `k` | Navigate list |

## Certs Tab

| Shortcut | Action |
|----------|--------|
| `r` | Regenerate CA certificate |
| `e` | Export CA PEM |
| `w` | Open certificate installation wizard |
| `q` | Quit |

## Global

| Shortcut | Action |
|----------|--------|
| `q` | Quit ProxyBot |
| `c` | Clear all filters |
| `?` | Show this help |
