# 键盘快捷键

ProxyBot TUI 支持完整的键盘导航。以下是所有可用的快捷键。

## 代理控制

| 快捷键 | 操作 |
|--------|------|
| `r` | 启动/停止代理 |
| `p` | 切换 pf（数据包过滤） |
| `n` | 切换 DNS 服务器 |

## 导航

| 快捷键 | 操作 |
|--------|------|
| `Tab` | 下一个标签页 |
| `Shift+Tab` | 上一个标签页 |
| `j` | 下移（列表中） |
| `k` | 上移（列表中） |
| `Enter` | 选择/确认 |

## 流量标签页

| 快捷键 | 操作 |
|--------|------|
| `m` | 按方法筛选 |
| `f` | 按主机筛选 |
| `o` | 按状态码筛选 |
| `a` | 按应用标签筛选 |
| `/` | 打开搜索 |
| `x` | 清除所有筛选 |
| `Esc` | 取消输入 |
| `1` / `2` / `3` | 切换详情子标签页（请求头 / 请求体 / WebSocket 帧） |

## 规则标签页

| 快捷键 | 操作 |
|--------|------|
| `a` | 添加规则 |
| `e` | 编辑规则 |
| `d` | 删除规则 |
| `j` / `k` | 列表导航 |

## 设备标签页

| 快捷键 | 操作 |
|--------|------|
| `a` | 切换 ADB（USB 调试） |
| `e` | 编辑设备规则覆盖 |
| `j` / `k` | 列表导航 |

## 证书标签页

| 快捷键 | 操作 |
|--------|------|
| `r` | 重新生成 CA 证书 |
| `e` | 导出 CA PEM |
| `w` | 打开证书安装向导 |
| `q` | 退出 |

## 全局

| 快捷键 | 操作 |
|--------|------|
| `q` | 退出 ProxyBot |
| `c` | 清除所有筛选 |
| `?` | 显示此帮助 |
