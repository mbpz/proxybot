# Historical implementation records

The plans and specs below document past design work. They are retained for
decision archaeology, not as proof that a feature is supported, complete, or
present in the current product.

The active sources of truth are current code and tests,
[`CONTEXT.md`](https://github.com/mbpz/proxybot/blob/main/CONTEXT.md), and the
[product roadmap](../roadmap.md). Revalidate any historical plan against
those sources before implementation.
