# Rockxy Community evidence ledger

## Fixed reference and boundary

This ledger records a clean-room review of the public [Rockxy Community
repository](https://github.com/RockxyApp/Rockxy/tree/6a676d631820b577cf3a651c78d856733a7df995),
captured on 2026-08-19 at commit
`6a676d631820b577cf3a651c78d856733a7df995`.

- The reviewed public source boundary is [AGPL-3.0-or-later](https://github.com/RockxyApp/Rockxy/blob/6a676d631820b577cf3a651c78d856733a7df995/LICENSE).
- The fixed public reference artifacts are [README.md](https://github.com/RockxyApp/Rockxy/blob/6a676d631820b577cf3a651c78d856733a7df995/README.md), [LICENSE](https://github.com/RockxyApp/Rockxy/blob/6a676d631820b577cf3a651c78d856733a7df995/LICENSE), and [LICENSING.md](https://github.com/RockxyApp/Rockxy/blob/6a676d631820b577cf3a651c78d856733a7df995/LICENSING.md).
- Official downstream DMG behavior and private/Pro behavior are excluded from the Community comparison. They are explicit boundary rows, not implementation targets.

Evidence grades are deliberately cumulative: `documented` means a public claim is recorded; `source-backed` means a fixed public source path supports the capability; `test-backed` means a fixed public test path supports it; `observable-build` means a reproducible build exposes the behavior; and `release-proven` means a published artifact independently proves it. A README claim alone is never parity-scope evidence.

ProxyBot evidence is recorded as `source:<path>`, `test:<path>`, or `docs:<path>`. A row's status describes evidence currently present in this repository, not roadmap intent.

## Clean-room method

The review inspects public behavior and public protocols only. This ledger records reference paths and independent behavior descriptions; ProxyBot implementations must be independently designed for its Rust/Tauri architecture, with independently authored fixtures. Do not copy Rockxy source, tests, assets, product copy, icons, or images.
