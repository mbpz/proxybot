Mode 2 — Side-router / gateway (experimental)

Not recommended yet: macOS pf redirect delivery is unreliable and a failed/stopped gateway can leave the device without internet. Keep the phone on automatic IP when you are not actively testing this mode.

Start the CLI with proxybot start --gateway, then set the device Wi-Fi gateway to … (DNS can stay on the router). HTTP/HTTPS is redirected to ProxyBot; other traffic is NATed.

HTTP proxy mode needs the CA trusted on the device before HTTPS can be decrypted: iOS Settings → General → About → Certificate Trust Settings; Android install as a user CA. Certificate-pinned apps will refuse interception — that is expected.

Custom ports: proxybot start --proxy-port … --transparent-port … --web-port …
