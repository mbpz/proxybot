Connect a device

Mode 1 — HTTP proxy (no admin)
Set the device Wi-Fi HTTP proxy to …, then open … on the device and install the CA.

Mode 2 — Side-router / gateway (pf, needs admin)
Start the CLI with proxybot start --gateway, then set the device Wi-Fi gateway to … (DNS can stay on the router). HTTP/HTTPS is redirected to ProxyBot; other traffic is NATed.

Both modes need the CA trusted on the device before HTTPS can be decrypted: iOS Settings → General → About → Certificate Trust Settings; Android install as a user CA. Certificate-pinned apps will refuse interception — that is expected.

Custom ports: proxybot start --proxy-port … --transparent-port … --web-port …
