ProxyBot device setup

This page is served by the Mac running ProxyBot. Do not close capture on the Mac while installing.

1. Install the ProxyBot CA

Download and install the certificate on this device:

Download CA certificate

iOS: after downloading, go to Settings → General → VPN & Device Management to install the profile, then Settings → General → About → Certificate Trust Settings and enable full trust for “ProxyBot Local CA”.
Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate.

2. Capture this device’s traffic

Mode 1 · HTTP proxy (no admin): Wi-Fi → HTTP proxy → Manual → server {{PROXY}}. Leave gateway and DNS unchanged.

Mode 2 · Gateway Beta (Mac running with sudo proxybot gateway start): Wi-Fi → configure IP → gateway {{GATEWAY}}, HTTP proxy off, keep the current DNS. Requires a separately installed sing-box; TCP/80/443 is intercepted, UDP/DNS stays direct.

Certificate-pinned apps will refuse decryption; that is an application security boundary, not a ProxyBot failure.

3. Verify

Open http://example.com, then https://example.com. Both should appear on the Mac’s ProxyBot web UI (Live tab).

4. Clean up

When finished: turn the Wi-Fi proxy off (or restore the gateway), stop capture on the Mac, and remove the CA from the device.
