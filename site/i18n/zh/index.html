    ProxyBot

    面向开发者的 macOS HTTPS MITM 代理

    [![macOS](https://img.shields.io/badge/macOS-✓-blue?style=for-the-badge)](https://github.com/mbpz/proxybot) [![Rust](https://img.shields.io/badge/Rust-✓-orange?style=for-the-badge)](https://github.com/mbpz/proxybot) [![TUI + GUI](https://img.shields.io/badge/TUI+GUI-✓-green?style=for-the-badge)](https://github.com/mbpz/proxybot)

    功能特点

    - **透明代理** — 无需逐应用配置代理。macOS `pf` 自动将手机所有流量重定向。 - **应用分类** — 流量按应用自动分组：微信、抖音、支付宝等。 - **完整 HTTPS 解密** — MITM + 动态生成证书。加密流量明文可见。 - **键盘驱动的 TUI** — 开发者友好的终端 UI。9 个标签页无需鼠标即可操作。 - **Yew GUI (Beta)** — 全新 Rust + WebAssembly 构建的桌面 GUI。无需 Node.js。 - **规则引擎** — 直连、代理、拒绝、远程映射、本地映射 — 完全控制流量。

    安装

    brew install mbpz/proxybot/proxybot-tui

    设置步骤

    1. 将手机连接到与 Mac 相同的 WiFi 网络
    2. 将手机的网关和 DNS 设置为 Mac 的 IP 地址
    3. 从 证书 标签页导出 CA 证书 → AirDrop 到手机
    4. 在 设置 → 通用 → 关于 → 证书信任设置 中信任 CA
    5. 运行 proxybot-tui 并按 r 启动代理

    查看 Mac 的 IP 地址：

    ipconfig getifaddr en0

    架构

    手机 --[WiFi]--> Mac (pf 重定向 :80/:443) --> ProxyBot (MITM) --> 互联网
                                                             |
                                                             +--> DNS 服务器（记录查询，关联应用）
